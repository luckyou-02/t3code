# Local access

Open the desktop app to use its Windows backend. To use a WSL distro, open
**Settings > Sharing & access > WSL backend**.

Run `t3` to start the server and open the local web client. If the server is
already running, run `t3 pair` and open the printed URL in a browser on this
machine. Use **Settings > Sharing & access > Authorized clients** to revoke
browser sessions and unused pairing links.

For a persistent local server, see [Running T3 Code in the background](./background-service.md).
